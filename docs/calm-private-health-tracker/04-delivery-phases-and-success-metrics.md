# Delivery Phases and Success Metrics

## Phase Plan

### Phase 1 - Foundation (Week 1-2)

Scope:
- Finalize UX patterns and content tone pack.
- Implement onboarding with mode selection.
- Implement baseline privacy defaults and settings entry points.

Exit criteria:
- New user can finish onboarding and reach home in under 3 minutes.
- Notification privacy default verified.
- Settings exposes privacy controls within two taps from home.

### Phase 2 - Core Tracking (Week 3-5)

Scope:
- Build cycle timeline with period window and optional fertility estimate.
- Implement symptom logging with quick-add and notes.
- Link symptom entries to timeline overlays and daily summaries.

Exit criteria:
- Users can log a symptom in under 20 seconds median time.
- Timeline reflects corrected period dates correctly.
- Weekly/monthly symptom trends visible.

### Phase 3 - Pregnancy Module (Week 6-7)

Scope:
- Build week-by-week pregnancy tracking and trimester context.
- Add weekly check-ins and basic milestone reminders.
- Integrate pregnancy context with symptom summaries.

Exit criteria:
- Pregnancy users can update weekly check-in in a single pass.
- Reminder settings are user-customizable and quiet by default.
- Safety disclaimer present on sensitive screens.

### Phase 4 - Trust and Release Readiness (Week 8)

Scope:
- Privacy center completion (data transparency, export, delete).
- App lock hardening and app preview masking verification.
- Usability pass with target users in Malaysia.

Exit criteria:
- Export and deletion flows validated end-to-end.
- No gamification elements in production candidate.
- Core trust and calm UX checks passed.

## MVP Success Metrics

- Onboarding completion + first log in under 3 minutes.
- At least 80% of active users log one or more symptoms weekly.
- Privacy setting discoverability: reachable in two taps from home.
- Prediction confidence messaging understood in usability interviews.
- Zero release blockers related to sensitive content exposure in notifications.

## Delivery Risks and Mitigations

- Risk: mistrust from unclear data usage.
  - Mitigation: plain-language privacy center and explicit consent moments.
- Risk: engagement pressure from over-designed reminders.
  - Mitigation: generic default notification text and easy opt-out controls.
- Risk: prediction misinterpretation as medical advice.
  - Mitigation: confidence labeling and repeated informational disclaimer.
