# Calm, Private Health Tracker

This package implements the approved MVP plan for a women-focused health tracker in Malaysia with a calm, private, and trustworthy experience.

## Included Specs

- `01-ux-principles-and-tone.md`: UX principles, voice, and visual guidance.
- `02-core-user-flows.md`: Onboarding, home, cycle, pregnancy, and symptom flows.
- `03-privacy-and-trust-spec.md`: Privacy defaults, app lock, notifications, and data rights.
- `04-delivery-phases-and-success-metrics.md`: Phased delivery plan and measurable MVP outcomes.

## Scope

- Mobile-first product direction.
- No gamification patterns.
- Core functional areas:
  - Cycle timeline
  - Pregnancy tracker
  - Symptom logging
